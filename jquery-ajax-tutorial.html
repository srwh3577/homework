1. 什麼是 AJAX？

AJAX 是 Asynchronous JavaScript and XML 的縮寫，意思是 「非同步的 JavaScript 與資料交換」。它讓網頁可以在 不重新整理整個頁面 的情況下，與伺服器交換資料並更新部分內容。

常見的應用場景：

  • 輸入帳號時即時檢查是否已被註冊
  • 無限捲動載入更多文章
  • 送出表單後不跳頁，直接顯示結果
  • 下拉選單連動（選縣市後自動載入鄉鎮）
為什麼用 jQuery？ 原生的 XMLHttpRequest 寫起來繁瑣， jQuery 把它包裝成簡潔好用的 API。雖然現代瀏覽器已有 fetch()， 但許多既有專案仍大量使用 jQuery AJAX，理解它仍然很重要。

2. 前置作業：載入 jQuery

使用 jQuery AJAX 前，必須先在 HTML 中載入 jQuery 函式庫。最簡單的方式是用 CDN：

<!-- 放在 <head> 或 </body> 前 -->
<script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>

接著，所有 AJAX 程式碼建議寫在 $(document).ready() 內，確保 DOM 已載入：

$(document).ready(function () {
  // 你的 AJAX 程式碼寫在這裡
});

// 簡寫，效果完全相同：
$(function () {
  // ...
});

3. 核心方法：$.ajax()

$.ajax() 是所有 jQuery AJAX 方法的底層核心， 其它簡寫方法（$.get、$.post）都是它的包裝。 它接收一個「設定物件」作為參數： 

$.ajax({
  url: "https://jsonplaceholder.typicode.com/posts/1",  // 請求網址
  method: "GET",        // 請求方法：GET / POST / PUT / DELETE
  dataType: "json",    // 預期伺服器回傳的資料型態
  data: { id: 1 }     // 要送出的資料
})
.done(function (response) {
  // 請求成功：response 就是伺服器回傳的資料
  console.log(response);
})
.fail(function (xhr, status, error) {
  // 請求失敗
  console.error("發生錯誤：", error);
})
.always(function () {
  // 不論成功失敗都會執行（例如關閉 loading 動畫）
});

4. 常用設定參數

參數說明範例值
url請求的目標網址（必填）"/api/users"
methodHTTP 方法（舊版用 type）"GET" / "POST"
data送往伺服器的資料{ name: "王小明" }
dataType預期回傳格式"json" / "html" / "text"
contentType送出資料的格式"application/json"
timeout逾時時間（毫秒）5000
headers自訂請求標頭{ Authorization: "Bearer ..." }
success成功的回呼（舊式寫法）function(data){...}
error失敗的回呼（舊式寫法）function(xhr){...}
送 JSON 給後端時要注意： 預設 data 會被轉成 name=王小明&age=20 這種表單格式。若後端要收 JSON，需設定 contentType: "application/json" 並用 JSON.stringify(data) 包裝資料。

5. 簡寫方法

對於常見情境，jQuery 提供更簡短的寫法：

$.get() — 發送 GET 請求

$.get("https://jsonplaceholder.typicode.com/posts/1", function (data) {
  console.log(data.title);
});

// 帶查詢參數
$.get("/api/search", { q: "jquery", page: 2 }, function (data) {
  console.log(data);
});

$.post() — 發送 POST 請求

$.post("/api/users", { name: "王小明", age: 25 }, function (response) {
  console.log("建立成功，ID：" + response.id);
});

$.getJSON() — 取得 JSON 資料

$.getJSON("https://jsonplaceholder.typicode.com/users", function (users) {
  $.each(users, function (i, user) {
    console.log(user.name);
  });
});

$(selector).load() — 直接把回應塞進元素

// 把 page.html 內 #content 區塊的內容載入到 #result
$("#result").load("page.html #content");

6. 處理回應：done / fail / always

$.ajax() 回傳一個 Promise 物件（jqXHR）， 推薦使用鏈式的 .done() / .fail() / .always() 來處理結果， 取代舊式的 success / error 設定參數：

方法觸發時機
.done(fn)請求成功時執行
.fail(fn)請求失敗時執行（404、500、逾時、網路錯誤等）
.always(fn)無論成功或失敗都執行
 
const request = $.ajax({ url: "/api/data" });

request.done(data  => console.log("成功", data));
request.fail(err   => console.log("失敗", err));
request.always(()  => console.log("結束"));

8. 錯誤處理與常見問題

完整的錯誤處理範例

$.ajax({
  url: "/api/data",
  timeout: 5000
})
.fail(function (xhr, status, error) {
  if (status === "timeout") {
    alert("請求逾時，請稍後再試");
  } else if (xhr.status === 404) {
    alert("找不到資源");
  } else if (xhr.status === 500) {
    alert("伺服器錯誤");
  } else {
    alert("發生未知錯誤：" + error);
  }
});
CORS 跨域問題： 當請求的網域與目前頁面不同時， 瀏覽器會基於同源政策阻擋，主控台會出現 No 'Access-Control-Allow-Origin' header 錯誤。 這需要由伺服器端設定允許跨域，前端無法單方面解決。
小技巧： 用 $(document).ajaxStart() 與 $(document).ajaxStop() 可以全域控制 loading 動畫的顯示與隱藏， 不必在每個請求裡重複寫。
